Write DataFusion and Spice SQL with completion, navigation and local error checking in DataGrip and IntelliJ IDEA with Database Tools, on IDE builds 261 through 263.

  • Product-specific parsing, highlighting, completion, documentation and local SQL diagnostics.
  • Separate live catalog inventories, explicit refresh and SQL reference navigation.
  • Apache Arrow Flight SQL JDBC connection templates for each product.
  • Independent, off-by-default Brikk PIPE generated-SQL preview and run-to-stage.

Background native verification is unavailable. The plugin does not execute, prepare or EXPLAIN your SQL to validate the editor. Connection and database-tree behavior depend on the installed JDBC driver and server. DataFusion deployments must expose the required Flight SQL and information-schema contract.

Reading the current namespace and selecting schemas for introspection are supported. Generated console namespace switching is not supported. SQL DDL requires a supporting server catalog and permissions; the plugin does not enable server write access.

Bundled metadata targets DataFusion 55.2.0 and Spice 2.4.0. Other versions use labeled fallback metadata rather than an exact-version support claim. See the README for setup and version-specific upstream limitations.
